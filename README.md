## What I Built
I built **TrailBuddy**, an open-source AI outdoor companion that helps people quickly plan and start local outdoor activities like hikes, park walks, birdwatching sessions, and short run routes.

The app keeps screen time short: users answer a few prompts (time available, activity type, weather tolerance), then receive a simple plan and checklist to get outside immediately.

## How I Built It
TrailBuddy is built around open innovation:
- **Open-weight model** for activity recommendations and concise outdoor plans
- **Open-source agent workflow** for prompt orchestration and response formatting
- **Local-first inference option** so users can run recommendations without always depending on cloud APIs

Tech stack:
- Frontend: lightweight web UI
- Backend: API service that handles routing, prompts, and location-aware activity suggestions
- AI layer: open-weight model + prompt templates tuned for fast, actionable outdoor plans

## Why Does Open Innovation Matter?
Open innovation made this project practical and trustworthy:
- Users can run models locally, which improves privacy for sensitive location habits
- The model and behavior can be adapted by the community for different climates, regions, and accessibility needs
- Costs stay low compared to closed APIs, making the project easier to maintain and share
- The transparency of open tools made it easier to debug and improve recommendation quality
